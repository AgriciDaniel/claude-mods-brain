# Changelog

## 1.0.0 - 2026-10-03

First public release, tested on Claude Code 2.1.288.

- 100+ notes on Claude Code mods: anatomy, the hook chain, every event family, the `$` API, render
  sites, limits, the lifecycle from first build to publishing, the trust model, and organization
  controls.
- Recipes for a status band, a pane, a slash command, a tool-call guard, migrating settings hooks,
  auditing a third-party mod, publishing, and re-verifying after a release.
- A catalog of 40 built-in, official, and community mods with pinned commits and verdicts.
- A 50-source ledger and a claim ledger with verdicts and second sources; six canon summaries; a
  contradictions register.
- Offline tools: a type-definitions importer, a drift check (names, signatures, and limits), a static
  mod scanner, and report renderers, with JSON Schemas and tests.
