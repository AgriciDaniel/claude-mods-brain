# Vault instructions

This vault is Claude Mods Brain, tested on Claude Code 2.1.288. Check `claude --version` first: a newer
build means API notes may be stale until `wiki/flows/Research Refresh Workflow.md` runs.

Read order:

1. `wiki/hot.md`
2. `wiki/index.md`
3. `wiki/meta/CONVENTIONS.md`
4. The relevant flow, concept, entity, decision, or deliverable note

Rules:

- Use flat YAML frontmatter and wikilinks; note shape and confidence tags follow `wiki/meta/CONVENTIONS.md`.
- Keep `hot`, `index`, `overview`, and `log` current.
- Cite the type definitions by line range or a dated official URL for API claims.
- Never install, enable, or load a mod without the user's approval.
- No credentials, tokens, or private data. No em or en dashes.
